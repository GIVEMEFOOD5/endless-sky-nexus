🧩 Page Features

What each page on the site currently does (and is planned to do).

🛰️ Ship & Outfit Data Viewer Live
  • Searchable, filterable card grid of ships and outfits
  • Category, plugin, and attribute-based filters with clear-all option
  • Multi-attribute sorter with drag-style reordering and per-sort averages
  • Detailed modal view with tabbed attributes, description, and stacking notes
  • Plugin picker for scoping results to specific installed/local plugins
  • Tooltips on hover for derived / calculated attribute values
📊 Compare Live
  • Sticky bottom compare bar with per-item quantity controls
  • Slide-up full-screen comparison panel
  • Toggle between column view and full attribute table view
  • Group comparisons — bundle multiple ships/outfits into one column
  • Best/worst value highlighting per attribute row
  • Fleet summary banner for aggregate stats across a selection
⚔️ Battle Simulator Live
  • Ship-vs-ship matchup builder with searchable ship slots
  • Team mode supporting multiple teams with custom names and colors
  • Simulated combat timeline with phase-by-phase breakdown
  • HP-over-time chart and side-by-side stat comparison
  • Weapon loadout breakdown per ship, including ammo stock summary
  • Battle matrix and rankings view for multi-ship tournaments
  • Responsive mobile layout with stacked comparison rows
🔧 Ship Builder Live
  • Full outfit picker grouped by category, with hardpoint index tracking
  • Live outfit-space bar showing used vs. available capacity
  • Editable attribute panel for on-the-fly stat tweaking
  • Expandable outfit rows showing full stats, description, and image
  • Save/load builds, with support for local (unpublished) plugin builds
  • Raw output/code box for exporting the finished ship definition
🔧 Plugin Manager Live
  • Full list of all plugins currently added to this project
  • The current status for the parser (running or idle)
  • Ability to add plugins by either ZIP or URL
  • It can edit the names or links of plugins
  • It can remove plugins from the list so if people want to test a plugin then they can add or remove it them selves
💾 Saves & Account Live
  • Full list of added pilots to this project
  • The ability to add your save files as many as you want
  • It gives you a fleet break down and some basic info on the ships
  • It tells you what planets you have each items stored on and any items you have in your cargo
  • It tells your your income and licenses
  • It informs you of the current plugins you have active and which of those it can find within this data viewer
